# Era Landing Page

Промпт v1 — настройка проекта и первый экран

Отправлять в Lovable целиком, одним сообщением. Границы: только первый экран. Остальные секции главной — следующими промптами.

Создай landing page для сервиса «Моя.Эра». Тёмная тема, атмосфера дорогого салона.

В этом промпте делаем только первый экран (hero, высота 100vh). Ниже первого экрана пока ничего не создавай — секции добавим следующими промптами.

Шрифты

Подключи из Google Fonts:

Unbounded — заголовки

Onest — весь остальной текст

JetBrains Mono — числа, координаты, служебные подписи

Цветовые токены

Все цвета — только через CSS-переменные. Ни одного захардкоженного hex в компонентах.

--bg-page: #03191E;
--surface-1: #063F47;
--surface-2: #086374;
--accent: #7A5DA8;
--accent-secondary: #195F60;
--depth: #3A245D;
--text-primary: #E6F0EF;
--text-secondary: #9FBAB9;
--text-accent: #C3AEE4;
--border: #0E4F58;


Строгое правило контраста:

--accent (#7A5DA8) используется только как заливка — фон кнопок, фон элементов. Белый текст на нём читается

--accent никогда не используется как цвет текста — на тёмном фоне он нечитаем

Для текста-акцента, ссылок и подписей используй --text-accent (#C3AEE4)

Первый экран — структура

Высота 100vh. Три слоя по глубине, каждый следующий темнее и резче предыдущего.

Слой 1 (дальний) — звёздное небо

Canvas на весь экран, фон --bg-page. Нарисуй звёзды программно, не картинкой.

Правила генерации, чтобы небо выглядело настоящим:

Примерно 220 звёзд на весь экран

Распределение неравномерное: сгенерируй 7–9 случайных центров скоплений и размести около 70% звёзд вокруг них, остальные 30% рассыпь равномерно. Между скоплениями должна оставаться заметная пустота

Яркость разная: около 8 звёзд с радиусом 1.6px и непрозрачностью 0.9; около 40 — радиус 1.1px, непрозрачность 0.5; остальные — радиус 0.6px, непрозрачность 0.25

Цвет звёзд: --text-primary

Медленный общий дрейф всего поля: полный оборот за 120 секунд

Мерцание: случайные 5 звёзд одновременно плавно меняют непрозрачность с периодом 3 секунды

Поверх canvas — одно мягкое радиальное пятно туманности в правом верхнем углу: радиальный градиент из --depth (непрозрачность 0.35) в полную прозрачность, радиус примерно 45% ширины экрана. Ровно два стопа, никаких многоцветных градиентов.

Слой 2 (средний) — кольцо шести направлений

Позиция: левая половина экрана, по вертикали примерно по центру.

Это главный светящийся объект экрана — самый контрастный элемент композиции.

Геометрия:

Круг диаметром 480px

Шесть элементов на окружности, ровно 60° между соседями

Активная позиция зафиксирована сверху по центру круга. Вращается кольцо, активный слот остаётся на месте

Центр круга занят: название активного направления (Unbounded, 28px), одна строка описания под ним (Onest, 15px, --text-secondary), кнопка под ними

Шесть направлений (это единственный источник данных, вынеси в один массив в коде, на который ссылается и кольцо, и центр):

Матрица судьбы — «Твой рисунок в 22 арканах»

Натальная карта — «Небо в минуту твоего рождения»

Дизайн человека — «Как ты устроен на самом деле»

Нумерология — «Числа, из которых ты собран»

Таро — «Вопрос, заданный вовремя»

Совместимость — «Вы двое как одна система»

Каждый элемент кольца — круг диаметром 72px, фон --surface-1, граница 1px --border. Внутри — простой геометрический глиф линиями цвета --text-secondary. Активный элемент: фон --surface-2, граница 1px --text-accent, диаметр 88px.

Свечение центра: радиальный градиент из --surface-2 (непрозрачность 0.4) в прозрачность, радиус 60% от ширины блока кольца. Свечение медленно «дышит»: непрозрачность плавно ходит между 0.3 и 0.45 с периодом 10 секунд.

Управление:

Перетаскивание мышью и свайп вращают кольцо

В покое кольцо вращается само: полный оборот за 60 секунд

При наведении мышью или касании автовращение останавливается

Клик по элементу доводит его до активной позиции

Слой 3 (передний) — размытая дуга

Внизу экрана — фрагмент гораздо большего кольца: дуга окружности радиусом примерно 1400px, центр которой находится ниже экрана. Видна только верхняя часть дуги, она пересекает нижнюю треть экрана.

Цвет: --bg-page, затемнённый до почти чёрного

Размытие 12px

Непрозрачность 0.85

Дуга обрезана краями экрана слева и справа

Это передний план. Он должен читаться как тёмный силуэт, а не как элемент интерфейса.

Зерно поверх всего

На весь первый экран, поверх всех трёх слоёв — накладка зерна. SVG-фильтр feTurbulence с baseFrequency 0.9, непрозрачность 4%, pointer-events: none.

Это обязательный элемент: без зерна градиенты выглядят пластиковыми.

Заголовок

Позиция: правая половина экрана, по вертикали по центру.

Три слова сменяют друг друга, каждое со своей подстрокой:

Слово Подстрока ТОЧКА Дата, время, место. С этого начинается всё СУДЬБА Не приговор. Рисунок, который можно прочитать СХОДИТСЯ Шесть систем считают тебя по-разному. И сходятся

Вёрстка:

Слово: Unbounded, размер 88px, вес 700, цвет --text-primary, заглавные буквы

Подстрока: Onest, 18px, цвет --text-secondary, под словом с отступом 24px

Контейнер слова имеет фиксированную ширину, рассчитанную по самому длинному слову «СХОДИТСЯ». Слова внутри выравниваются по левому краю контейнера. Без фиксации ширины подстрока и кнопка будут прыгать при смене слов

Контейнер подстроки тоже фиксированной высоты по самой длинной строке

Анимация смены:

Каждое слово показывается 3.5 секунды

Переход 500 мс: старое слово исчезает и уходит вверх на 8px, новое появляется снизу со смещением 8px, easing ease-out

Слово и подстрока меняются одновременно, как пара

Не используй эффект печатной машинки

Разметка для SEO: элемент h1 должен содержать все три слова в HTML одновременно. Переключай видимость через CSS-классы, а не подстановкой текста через JavaScript. Иначе поисковик увидит пустой заголовок.

Под подстрокой — кнопка «Рассчитать бесплатно»: фон --accent, текст белый, скругление 8px, паддинг 16px 32px, Onest 16px.

Хедер

Прозрачный, поверх первого экрана. Слева логотип «Моя.Эра» (Unbounded, 20px). Справа — ссылки: Направления, Как это работает, Тарифы. Цвет ссылок --text-secondary, при наведении --text-accent.

Мобильная версия (до 768px)

Кольцо: не полный круг, а дуга снизу примерно на 180°. Полный круг на узком экране съедает всю высоту. Активный элемент — в верхней точке дуги

Заголовок: над кольцом, размер слова 48px, подстрока 15px, выравнивание по левому краю

Диаметр дуги: 320px

Передняя размытая дуга сохраняется, но её радиус уменьшается до 700px

Количество звёзд уменьши до 120

Движение и доступность

При prefers-reduced-motion: reduce отключаются:

ротация слов заголовка (остаётся «СУДЬБА»)

автовращение кольца (остаётся статичным, элементы кликабельны)

дыхание свечения

дрейф и мерцание звёзд

Чего делать НЕ нужно

Никакого glassmorphism, матовых стёкол и backdrop-blur на карточках

Никаких неоновых контуров и свечения по краям элементов

Никаких градиентов на кнопках, тексте и границах — градиенты только фоном

Никаких готовых картинок космоса — небо генерируется кодом
